# 🏔️ Mountain's Experience

## 📝 Descripción
Landing page responsiva que muestra diferentes actividades de montaña. Desarrollada con HTML, CSS y JavaScript vanilla, esta página web presenta tres formas diferentes de disfrutar de la montaña: senderismo, escalada y vías ferratas.

## ✨ Características principales
- 📱 Diseño totalmente responsive que se adapta a cualquier dispositivo.
- 🍔 Menú hamburguesa para navegación móvil.
- 🎲 Botón interactivo que muestra una tarjeta aleatoria en un modal.
- 🎯 Navegación suave (smooth scroll) a las diferentes secciones.

## 🚀 Instalación y uso
1. Clona este repositorio:
   ```bash
   git clone https://github.com/JavierBres/reto_frontend.git
   ```
2. Abre el archivo `index.html` en tu navegador preferido.
3. ¡Explora las diferentes actividades de montaña!

## 🎯 Funcionalidades
1. **Navegación responsiva**
   - Menú hamburguesa en dispositivos móviles.
   - Navegación suave entre secciones.

2. **Modal interactivo**
   - Botón que muestra una tarjeta aleatoria.
   - Animaciones suaves de entrada/salida.
   - Cierre mediante botón o click fuera del modal.

3. **Diseño Adaptativo**
   - Layout flexible que se adapta a cualquier pantalla.
   - Imágenes responsivas.
   - Tipografía escalable.
