# RETO - FRONTEND

### Landing page construida con los lenguajes HTML, CSS y JavaScript, que se comporta de forma responsiva, la cual se puede ver en cualquier pantalla.
### Es una página web que muestra tres formas diferentes de disfrutar de la montaña. Tres disciplinas como el senderismo, la escalada y las vías ferratas.
### En la sección principal hay un botón, que al clicar emerge un modal de una de las tres tarjetas de forma aleatoria.
### En modo responsive, los links que estań en la barra de navegación, se convierte en un menú tipo hamburguesa.
### En la parte de abajo, está el footer con los datos de contacto, tanto el correo electrónico, como el enlace a la página de GitHub.
